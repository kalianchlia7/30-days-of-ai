# 30 Days of AI

Welcome to my **30 Days of AI** challenge.

This repository documents a month-long project in which I design, build, and publish one artificial intelligence or machine learning project each day. The goal of this challenge is to strengthen my understanding of machine learning, deep learning, natural language processing, computer vision, and applied AI through hands-on projects.

Rather than focusing only on theory, each project emphasizes practical implementation, experimentation, and real-world applications. Throughout the challenge, I explore a wide variety of models, algorithms, and techniques while building a portfolio of projects related to topics such as criminal justice, law, public policy, geopolitics, cybersecurity, and natural language processing.

Each project includes:

- A description of the problem being addressed
- An explanation of the machine learning or AI technique used
- Fully documented Python code
- Model evaluation and visualizations
- Discussion of limitations and potential improvements
- A project-specific README

This repository is also intended to serve as a personal learning record, documenting my progression from foundational machine learning models to more advanced AI systems over time.
